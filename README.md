# Sales Data Analysis using Excel

## Project Overview
This project analyzes retail sales data using Microsoft Excel.

## Tools Used
- Microsoft Excel
- Pivot Tables
- Pivot Charts

## Key Metrics
- Total Sales: 2,297,200.86

## Analysis Performed
- Monthly Sales Trend Analysis
- Sales Dashboard Creation
- Business Insight Generation

## Key Insights
- November recorded the highest sales performance.
- Sales showed a positive growth trend across the years.
- Q4 months contributed significantly to revenue.
- Seasonal fluctuations were observed throughout the year.
